Namuna dars

Kvadrat tenglama nima?

Keling, mavzuni sodda qilib tushunamiz.

5 daqiqa

Kvadrat tenglama — noma’lum sonning kvadrati qatnashgan tenglama. Uning umumiy ko‘rinishi quyidagicha:

ax² + bx + c = 0,   a ≠ 0

Bu harflar nimani anglatadi?

a, b, c — ma’lum sonlar, x esa biz topishimiz kerak bo‘lgan noma’lum son. Muhimi, a nolga teng bo‘lmasligi kerak.

Oddiy misol:
x² − 5x + 6 = 0. Bu yerda a = 1, b = −5, c = 6.

Yodda tuting

Kvadrat tenglamada x ning eng katta darajasi 2 bo‘ladi. Keyingi darsda diskriminant yordamida yechimlarni topishni o‘rganish mumkin.
